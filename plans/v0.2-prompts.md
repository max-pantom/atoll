# Atoll v0.2 — build prompts

Run from `~/Desktop/code/atoll`. Builders: `claude --model claude-sonnet-5-5 --effort medium`. Reviewer: Opus 5.5 `--effort low`. Run Builder A and B at the same time in two terminals.

## Shared rules (paste at the top of every prompt)

You're working on Atoll, a native Swift/SwiftUI macOS menu-bar app that draws a software Dynamic Island at the top centre of any display. It's a Swift package with no Xcode project; `scripts/` bundles the .app. Read plans/RESEARCH.md, plans/SPEC.md and the existing code before you start.
- Keep the look and motion exactly as they are. Reuse IslandMotion springs, the blur/scale content transition, the SF Pro Rounded `.island()` font, SF Symbols, `.numericText()` rolling numbers and `.symbolEffect(.replace)`. Don't redesign anything.
- Every new feature is a new activity in the existing activity and priority system, with its own on/off toggle in Settings (off by default if it needs a permission).
- Use SF Symbols, or the Icon Factory pack (factory.primitive8.cc/icons, repo max-pantom/icon-factory) when a symbol is missing.
- Never write tokens to files. Use the Keychain.
- Use only Apple frameworks, apart from the existing mediaremote-adapter.
- Add `--demo` support for every new activity so CI can screenshot it.
- Build with `swift build` and the bundle script. Keep CI green.
- Commit in small steps. Touch only the files you own (listed below) plus the shared registration points named here.

## Builder A — Clipboard, Quick capture, Downloads

Build three activities in `Sources/Atoll/Activities/Clipboard/`, `QuickCapture/` and `Downloads/`.

1. **Clipboard history**
   - Poll NSPasteboard changeCount about every 0.5 s.
   - Keep the last 20 items (text, image, file URLs).
   - Skip items marked `org.nspasteboard.ConcealedType` or `TransientType` (password managers).
   - Expanded view: a scrollable row/list with a preview, app source if known, and age.
   - Click copies an item back to the clipboard. Option-click pastes it into the frontmost app (needs Accessibility; ask only when the user enables it).
   - Add pin/unpin and a Clear all button.
   - Persist pinned items only, to Application Support.
2. **Quick capture**
   - A global hotkey (default ⌥⌘N, changeable in Settings) opens the island expanded with a text field.
   - Enter saves a note to Apple Notes. ⌘Enter saves a reminder through EventKit, with a natural-language date if one is easy to parse.
   - Show a brief ✓ confirmation in the island.
   - Notes go through AppleScript/NSAppleScript. Handle the Automation permission prompt gracefully.
3. **Downloads progress**
   - Watch ~/Downloads with FSEvents/DispatchSource for `.crdownload`, `.download`, `.part` and `.partial` files.
   - Show filename plus growing size (or a progress ring if the total is known through the download's extended attributes).
   - When it finishes, play a done pop with Reveal in Finder and Open buttons.
   - Show AirDrop arrivals as the same done pop when a new file lands with the AirDrop quarantine/where-from metadata.

Register each in the activity registry and Settings. Report the files you changed and any permissions each feature needs.

## Builder B — Focus timer, Meeting bar, Dev mode

Build three activities in `Sources/Atoll/Activities/Focus/`, `Meeting/` and `DevMode/`.

1. **Focus timer**
   - Presets 25/5, 50/10 and 90/15, plus a custom time.
   - Show compact progress as a thin ring hugging the island edge, with the time left in the rolling-number style.
   - Turn Do Not Disturb on and off by running user Shortcuts named "Atoll Focus On" and "Atoll Focus Off" through `shortcuts run`, and document how to create them. If the shortcuts are missing, skip this silently and show a hint in Settings.
   - Keep a session log (date, length, completed) in Application Support. Settings shows today's total.
2. **Live meeting bar**
   - Detect mic in use (CoreAudio `kAudioDevicePropertyDeviceIsRunningSomewhere`) and camera in use (CoreMediaIO `kCMIODevicePropertyDeviceIsRunningSomewhere`).
   - Show a small dot on the compact island: orange for mic, green for camera, like macOS.
   - Expanded view: which meeting is on (from the current calendar event), time left, and a mute toggle that sets the default input device's volume or mute.
   - Show a heads-up pop 2 minutes before the next event, with a Join button that reuses the existing link parser.
3. **Dev mode**
   - (a) GitHub Actions. In Settings, the user adds owner/repo pairs and a GitHub token (stored in the Keychain).
     - Poll each repo every 30 s, or every 10 s while a run is in progress.
     - Show running (spinner), success (✓) and failure (✗) with the workflow name. Clicking opens the run URL.
   - (b) Terminal pings. Register the URL scheme `atoll://notify?title=…&body=…&status=ok|fail`.
     - Ship a tiny `atoll` CLI script in the bundle's Resources that calls it.
     - Ship a zsh snippet (in docs/) that pings when a command runs longer than N seconds (default 10).
     - Show the ping as a short activity.
   - (c) Optional Vercel: only if a token is set, latest deployment state for chosen projects.

Register each in the activity registry and Settings. Report the files you changed and any permissions each feature needs.

## Reviewer — Opus 5.5, low effort (after A and B finish)

Review the v0.2 changes in this repo (`git diff v0.1.0..HEAD`) against the shared rules and the Builder A/B prompts in plans/v0.2-prompts.md.
- Check for main-thread blocking (polling, FSEvents, CoreAudio listeners), leaked timers and observers, and permission prompts that fire before a feature is enabled.
- Check for tokens outside the Keychain and clipboard capture of concealed items.
- Check that the priority system still has the right winner when several activities are live, and for any visual drift from the v0.1 look and motion.
- Check that `--demo` covers every new activity.
Write findings to plans/REVIEW-v0.2.md as Blockers / Should-fix / Nits with file:line. Don't change code.
